# KNIGHTFALL: RISE OF THE UNDEAD

A ready-to-open Godot 4 project for Windows 11. This is a playable foundation, not just a code sample.

## Open and run
1. Install Godot 4.x from https://godotengine.org/download/
2. Extract this ZIP to a normal folder.
3. Open Godot Project Manager.
4. Click **Import**, select `project.godot` from this folder.
5. Open the project and press **F6** or **F5**.

## Controls
- A / D or Left / Right: move
- Space / W / Up: jump
- J: light attack
- K: heavy attack
- L: dodge
- I: heal
- Esc: pause / resume
- R: restart after death

On-screen touch buttons are included for future mobile builds and can also be clicked with a mouse.

## What's included
- Side-scrolling landscape arena with a parallax-style night sky, ruins, fog, ground, and platforms
- Player movement, jump, dodge, stamina, health, light/heavy attacks and hit feedback
- Three enemy archetypes: shambling undead, fast ghoul, and armored undead
- A multi-phase boss encounter
- XP, gold, level-ups, potion healing, loot drops, and upgrade points
- HUD, pause/death/victory overlays, and touch controls
- Procedural visuals drawn by Godot scripts; no external asset downloads required

## Notes
This is a functional first playable build. It is designed to be expanded with additional levels, sprites, sound, equipment menus, and saved progression. The project uses Godot 4 GDScript and no paid plugins.
